# 카카오톡

스크립트는 이 폴더의 `kakao.py`다. 항상 `python -I -X utf8`로 실행한다. `pywin32`와 `psutil`이 필요하다.

```
python -I -X utf8 "<이 폴더>\kakao.py" rooms
python -I -X utf8 "<이 폴더>\kakao.py" read "<방이름>" 30
python -I -X utf8 "<이 폴더>\kakao.py" send "<방이름>" "<메시지>"
python -I -X utf8 "<이 폴더>\kakao.py" image "<방이름>" "<그림 경로>"
python -I -X utf8 "<이 폴더>\kakao.py" file "<방이름>" "<파일 경로>"
python -I -X utf8 "<이 폴더>\kakao.py" selftest
```

## 규칙

- 대화방은 미리 열려 있어야 한다. 방이름은 창 제목과 정확히 같아야 한다. 먼저 `rooms`로 확인한다.
- 보내기는 사용자가 받는 사람과 내용을 직접 말했을 때만 한다. 보내기 전에 받는 사람과 내용을 한 줄로 알려준다. 보낸 뒤에는 `read`로 실제로 올라갔는지 확인한다.
- 사용자가 시키지 않은 자동 답장은 하지 않는다.
- 테스트는 나와의 채팅 방에서만 한다.
- 읽은 대화 내용은 사용자의 개인 정보다. 외부 서비스로 보내지 않는다.

## 되는 것과 안 되는 것

2026년 11월 13일에 Windows 10과 카카오톡 PC 버전에서 확인한 내용이다.

- `rooms`와 `read`는 백그라운드로 된다. 창이 가려져 있어도 된다. `read`는 클립보드를 잠깐 쓰고 글자만 되돌린다. 복사해 둔 파일이나 그림은 사라진다.
- `send`, `image`, `file`은 화면 조작 방식이다. 창이 맨 위로 올라오고 마우스가 움직인다. 백그라운드 전송은 안 된다. 입력칸에 글자는 들어가지만 신호로 보낸 Enter를 카카오톡이 무시한다.
- 보내기 전에 대화방이 앞에 왔는지 확인하고 아니면 아무것도 보내지 않고 끝낸다. 사진과 파일은 카카오톡 전송 확인 창이 뜬 걸 확인하고 Enter를 누른다.
- `send`는 2026년 11월 13일에 나와의 채팅 방에서 실제로 보내서 확인했다. `image`와 `file`은 같은 날 같은 방법으로 보내서 확인한 뒤 이 파일로 옮긴 것이다.
- `image`는 그림을 클립보드 이미지로 붙여넣어서 사진으로 보낸다. 그림 파일을 `file`로 보내면 사진이 아니라 파일로 간다.
- 닫힌 대화방 열기, 통화, 파일 다운로드는 없다.
- 이 기능들은 사용 중인 카카오톡 버전의 화면 배치에 기대고 있어서 업데이트되면 깨질 수 있다.
- 1대1 대화방에서는 @를 쳐도 멘션 목록이 뜨지 않는다.

## 조작할 때 주의

- 메인 창에서 Ctrl+A를 누르면 친구 추가 창이 뜬다.
- 창을 앞으로 가져오려고 Alt 키를 누르면 창 메뉴가 열린다. 창 안을 클릭해서 앞으로 가져온다.
- 화면 배율이 100%가 아니면 좌표를 쓰기 전에 `SetProcessDPIAware`를 호출한다.
- 창 클래스는 `EVA_Window_Dblclk`이고 입력칸은 `RICHEDIT50W`이고 대화 목록은 `EVA_VH_ListControl_Dblclk`이다.
